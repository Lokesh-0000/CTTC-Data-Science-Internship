# CTTC Data Science & AI Summer Internship

## Overview
This repository contains the coursework, projects, and Jupyter Notebooks completed during my 26-day Summer Internship at CTTC. The program provided hands-on experience in Data Science, Machine Learning, and Artificial Intelligence, following a structured progression from fundamental Python programming to advanced Deep Learning applications.

## Tech Stack & Tools
* **Languages:** Python
* **Data Manipulation:** NumPy, Pandas
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Regression, Classification, Unsupervised Learning (Scikit-Learn)
* **Deep Learning & AI:** Artificial Neural Networks (ANN), Natural Language Processing (NLP), Computer Vision

## Modules & Daily Progress

* **Day 1 - 3: Python Basics**
  * Core programming concepts, data structures, and syntax.
* **Day 4: NumPy**
  * Numerical computing, array operations, and mathematical functions.
* **Day 5 - 7: Pandas**
  * Data manipulation, cleaning, exploratory data analysis (EDA), and dataframe operations.
* **Day 7 - 8: Data Visualization**
  * Designing statistical plots and charts using **Matplotlib** and **Seaborn**.
* **Day 9 - 10: Regression Models**
  * Implementing linear and multiple regression algorithms for predictive modeling.
* **Day 11 - 12: Classification Models**
  * Building models to categorize data into discrete classes.
* **Day 13: Practice & Implementations**
  * Consolidating core machine learning and data science concepts.
* **Day 14: Unsupervised Learning**
  * Clustering techniques and pattern recognition in unlabeled data.
* **Day 15: Natural Language Processing (NLP)**
  * Text processing, feature extraction, and language modeling.
* **Day 16 - 17: Computer Vision**
  * Image processing and visual data extraction.
* **Day 18: Artificial Neural Networks (ANN)**
  * Designing and training deep learning architectures.

## How to Use
To explore the notebooks, you can view them directly on GitHub or run them locally:
1. Clone the repository: `git clone https://github.com/Lokesh-0000/CTTC-Data-Science-Internship.git`
2. Install the required dependencies: `pip install numpy pandas matplotlib seaborn scikit-learn tensorflow` (or your preferred ML libraries).
3. Launch Jupyter: `jupyter notebook`
